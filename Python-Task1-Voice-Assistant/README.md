# Voice Assistant Using Python

## About the Project
The Voice Assistant is a Python-based project that helps users perform simple tasks using voice commands. It uses speech recognition to understand user commands and provides responses through voice output.

## Features
- Voice command recognition
- Speech responses
- Open websites
- Tell the current time
- Perform basic tasks using voice commands

## Technologies Used
- Python
- SpeechRecognition
- Pyttsx3
- PyAudio

## Project Objective
The main objective of this project is to learn Python programming, speech recognition, and voice-based automation.
